실시간 멀티플레이어 체스

채팅 화면 안에서 대국실을 생성하고 다른 사용자와 실시간으로 체스를 플레이하거나 관전할 수 있는 기능입니다.

대국 진행, 관전, 기보, 타이머, 재접속 처리를 WebSocket으로 연결하고, 게임 상태와 결과는 서버가 최종적으로 관리하는 서버 권위(Server-Authoritative) 방식으로 구현했습니다.

서버 권위 기반 게임 상태 관리

체스 게임의 핵심 상태를 클라이언트가 아닌 서버에서 관리하도록 설계했습니다.

클라이언트는 수를 요청할 뿐, FEN·SAN·게임 결과 등의 값을 직접 결정하지 않습니다. 서버는 현재 보드 상태를 기준으로 요청된 수가 합법적인지 검증하고, 검증된 수를 적용한 뒤 새로운 게임 상태와 결과를 계산합니다.

따라서 클라이언트에서 임의로 FEN이나 승패 결과를 조작하더라도 서버의 게임 상태나 전적에 직접 반영되지 않습니다.

서버 기준 타이머 동기화

양쪽 플레이어의 타이머는 클라이언트의 단순 카운트다운이 아니라 서버가 계산한 deadline을 기준으로 동작합니다.

클라이언트는 서버와 자신의 시각 차이를 계산하고, 서버 시각을 기준으로 남은 시간을 표시합니다. 이를 통해 클라이언트별 로컬 시간 차이로 인해 타이머가 서로 다르게 표시되는 문제를 줄였습니다.

또한 WebSocket 연결이 일시적으로 끊기거나 체스 화면을 닫더라도 서버의 deadline을 기준으로 게임이 계속 진행되도록 구성했습니다.

WebSocket 기반 실시간 상태 동기화

대국실의 플레이어 상태, 관전자 목록, 게임 진행 상황, 기보, 타이머 및 게임 결과를 WebSocket을 통해 실시간으로 동기화합니다.

연결이 끊어진 경우에는 즉시 게임을 종료하지 않고 일정 시간 동안 재접속을 허용하며, 재접속한 사용자의 기존 대국 상태와 진영을 복구합니다.
