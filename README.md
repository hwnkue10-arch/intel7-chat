## 실시간 멀티플레이어 체스

채팅 서비스 내부에서 다른 사용자와 실시간으로 체스를 플레이하고 관전할 수 있는 기능을 구현했습니다.

대국실 생성부터 대국, 관전, 기보, 타이머, 재접속까지 WebSocket을 기반으로 실시간 처리하며, 게임 상태와 결과는 서버가 최종적으로 관리하는 Server-Authoritative 구조로 설계했습니다.

### 주요 기능

- **실시간 대국실**
  - WebSocket 기반 대국실 생성 및 참가
  - 백/흑 좌석 선택 및 관전자 목록 실시간 동기화
  - 대국 종료 후 결과 표시 및 자동 관전자 전환
  - 다음 대국을 위한 대기 상태 자동 전환

- **서버 권위 기반 체스 규칙 검증**
  - `python-chess`를 활용한 서버 측 합법 수 검증
  - 체크, 체크메이트, 캐슬링, 앙파상, 프로모션 지원
  - 스테일메이트, 기물 부족, 50수 규칙, 3회 동형 반복 무승부 처리
  - 상호 합의 무승부, 기권, 시간패 처리

- **타이머 동기화**
  - 서버의 절대 시각(deadline)을 기준으로 양쪽 타이머 관리
  - 클라이언트의 로컬 시간 차이에 영향을 받지 않는 타이머 구현
  - 체스 화면을 닫거나 WebSocket 연결이 일시적으로 끊겨도 서버 기준으로 대국 지속

- **WebSocket 재접속 처리**
  - 브라우저 새로고침 및 일시적인 WebSocket 연결 단절에 대한 재접속 유예
  - 재접속 성공 시 기존 대국방 및 플레이어 진영 복구
  - 연결 상태와 게임 상태를 분리하여 일시적인 네트워크 문제로 인한 게임 종료 방지

- **기보 및 복기**
  - 대국 진행에 따른 실시간 기보 저장 및 조회
  - 기보 클릭을 통한 이전 게임 상태 복기
  - 복기 후 최신 수로 복귀

- **전적 관리**
  - SQLite 기반 승·무·패 전적 영구 저장
  - 게임 종료 결과를 서버에서 확정한 후 전적에 반영
  - 채팅 닉네임 변경 사항을 대국자 및 관전자 목록에 실시간 반영

- **CSP 대응**
  - 외부 CDN에 의존하지 않도록 Chess.js를 로컬 정적 파일로 제공

### 기술 스택

| 구분 | 기술 |
| --- | --- |
| Backend | FastAPI, WebSocket, `python-chess` |
| Frontend | Vanilla JavaScript, Chess.js, CSS |
| Database | SQLite |
| 실시간 통신 | WebSocket |
| 게임 상태 관리 | Server-Authoritative |
| 타이머 동기화 | Server Deadline + Client Time Offset |

### 핵심 구현

#### 1. Server-Authoritative 게임 상태 관리

클라이언트가 게임 상태나 결과를 직접 결정할 수 있도록 하면 불법 수나 승패 조작이 발생할 수 있기 때문에, 게임의 핵심 상태와 결과를 서버가 관리하도록 설계했습니다.

클라이언트는 수를 서버에 요청하고, 서버는 현재 게임 상태를 기준으로 해당 수를 검증한 후 보드 상태와 게임 결과를 직접 계산합니다.

```text
Client
  │
  │ Move Request
  ▼
WebSocket Server
  │
  ├─ 플레이어 및 턴 검증
  ├─ 합법 수 검증
  ├─ 보드 상태 업데이트
  ├─ 게임 결과 계산
  └─ 최신 게임 상태 Broadcast
  │
  ▼
Players / Spectators
